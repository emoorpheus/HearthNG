# HearthNG for WebOS

HearthNG (by emoorpheus) is a fork of [Hearth for WebOS](https://github.com/rudra-avatar/Hearth) by rudra-avatar. These guides are Hearth's, with the name changed to HearthNG; the tests and user reports in them are Hearth's.

HearthNG is a quiet, fast home screen for LG TVs. It shows a clock, the weather and your apps in one neat row.

- **New here?** Start with the [Beginners guide](BEGINNERS-GUIDE.md). It explains every word and every step, like a story.
- **Want to know what HearthNG can do?** Read [Everything HearthNG can do](customizing.md).
- **Want to change how it looks?** See [Look](features/look.md), [Widget](features/widget.md) and [Wallpaper](features/wallpaper.md), or make a [custom theme](theme/theme-guide.md).
- **Something is wrong?** Open [Troubleshooting](troubleshooting.md).
- **Does it work on my TV?** See Hearth's [Tested TVs](COMPATIBILITY.md). HearthNG itself is tested on one TV only (LG OLED65M59LA, webOS 25).
- **Source:** HearthNG's source is the repository these pages come from. Hearth's: [github.com/rudra-avatar/Hearth](https://github.com/rudra-avatar/Hearth).
